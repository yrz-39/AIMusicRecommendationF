# StudyMood DJ

StudyMood DJ 是一个本地优先的学习场景音乐推荐工具。

用户用自然语言描述自己当前的学习状态，系统理解当前情境，并从用户自己的音乐库中选择、排序和解释适合现在播放的音乐。

## 核心流程

```text
自然语言 → 学习情境 → 个人音乐库 → 推荐 → 推荐理由 → 用户反馈 → 个性化
                                              ↓
                                     网易云一键播放（ncm-cli 官方通道）
```

## 项目原则

* Local First
* 推荐可解释
* 用户数据默认保存在本地
* AI 主要负责理解自然语言
* 核心推荐能力应可测试、可观察
* 外部服务失败不应让整个产品不可用（LLM 失败回退规则版，ncm-cli 缺失不影响推荐）
* 优先完成真实用户体验，而不是堆功能

## 技术栈

* **语言**：TypeScript（strict 模式）
* **核心**（`src/core`）：纯函数推荐引擎 —— LLM 优先/规则兜底的中文情境解析、六维评分、反馈亲和度，零 I/O，完全可单测
* **存储**（`src/storage`）：本地 JSON 文件（原子写入，`data/` 目录，不入 Git）
* **服务**（`src/server`）：Hono API，只监听 `127.0.0.1`
* **前端**（`src/web`）：React + Vite，樱花粉主题单页（主窗口 + 桌面小窗复用）
* **桌面**（`electron`）：Electron 壳，主窗口 ↔ 置顶小窗，内嵌同一 API
* **测试**：Vitest（166 例：解析器 / 引擎 / 存储 / API 集成 / ncm-cli 适配层）

## 开发与运行

要求：Node.js ≥ 20。

```bash
npm install        # 安装依赖

npm run dev        # 开发模式（API :8787 热重载 + Vite :5173 代理）
npm start          # 生产模式（构建后单进程，托管 API + 前端）

npm test           # 运行全部测试
npm run typecheck  # TypeScript 类型检查
npm run build      # 构建前端到 dist/web
npm run dist       # 打 Windows NSIS 安装包（需 ELECTRON_MIRROR=npmmirror）
```

浏览器模式启动：`npm run build && npm start`，然后打开 http://127.0.0.1:8787/。

## 首次运行

曲库为空时自动导入内置示例库（82 首）。在「音乐库」页导入自己的曲目：

* **网易云歌单一键导入**：粘贴歌单分享链接/短链/纯 id，整单抓取入库（按「歌名|歌手」跨来源去重）；
* **CSV**：粘贴或选择 `.csv` 文件，表头支持中英文，列名顺序不限、缺列可省；
* **JSON**：粘贴曲目对象数组。

导入后自动触发 **LLM 预标注**（按歌名/歌手/流派推断能量/情绪/人声密度，标注写入 learnEvents 可追溯）。

## LLM 配置（可选但推荐）

应用内「⚙ 设置 → LLM 智能理解」填写 API Key 即可（默认 DeepSeek，兼容任意 OpenAI 格式接口），保存立即生效。未配置时状态理解自动走本地规则版，功能不缺、精度略降。也可手动编辑本机 `.env`（`STUDYMOOD_LLM_API_KEY` / `STUDYMOOD_LLM_BASE_URL` / `STUDYMOOD_LLM_MODEL`）。

## 网易云联动（M8，Windows 实验性）

通过网易云**官方** ncm-cli（开放平台通道）实现"生成的歌单直接播放"：

1. **安装**：`npm install -g @music163/ncm-cli`（需 Node ≥ 18；播放还依赖 mpv，Windows 可 `winget install shinchiro.mpv`）；
2. **凭证**：到网易云音乐开放平台（developer.music.163.com）个人入驻，拿 AppId/PrivateKey 填进「⚙ 设置 → 网易云播放联动」保存（应用转写入 ncm-cli 配置）；
3. **登录**：终端运行 `ncm-cli login` 扫码（用你自己的账号，播放走你自己的会员权益）；
4. 设置页点「检测联动状态」显示就绪即可。

能力与边界（详见 DECISIONS.md 2026-09-26 各条）：

* **▶ 播放歌单**：逐首搜索匹配（宁可不播不播错）→ 内置 mpv 播放器出声，失败按类别归组显示；
* **遥控**：播放条 ⏮⏯⏭⏹ 直接控制交付队列，乐观更新即时反馈；交付开始会自动暂停正在放歌的网易云客户端（通过其全局暂停快捷键，默认 Ctrl+P，可配置）；
* **全库补位**：曲库填不满时长时，LLM 生成搜索词 → 全库搜索 → LLM 逐首评估是否符合当前情境 → 通过者以「网易云补充」进歌单，可试听、评价、一键入库；
* **双播放条**：ncm 播放器条（可遥控）与网易云客户端条（检测+学习）独立显示；
* **已知限制**：Windows 版客户端暂不支持被程序唤起（官方仅 macOS），VIP 歌在 mpv 通道拿不到音源——这类歌会如实标注，可在客户端手动听；客户端被唤起的能力上线后改 `STUDYMOOD_NCM_PLAYER=orpheus` 即整体切换。

## 普通用户使用说明

安装版（StudyMood DJ Setup）装好后直接打开即可：

1. **第一次启动**会出现三步引导；随时点右上角「？帮助」或「⚙ 设置」；
2. 「音乐库」页导入自己的歌（网易云歌单链接 / CSV / JSON），AI 自动预标注；
3. 在「推荐」页描述现在的状态（如「有点累，要写代码两小时，想听安静的歌」）→ 获得带理由的推荐；
4. 想要整段歌单，就在同一段话里写上时长（如「复习 40 分钟」），点「🎵 生成歌单」；配好网易云联动后点「▶ 播放歌单」直接出声；
5. 用 ❤️ / ✕ 反馈调整口味（未入库的补位歌也能评价，入库后自动生效）；
6. 右上角「⊞ 小窗」切换为置顶小窗，边学习边换歌。

**数据与备份**：所有数据保存在本机 `%APPDATA%\studymood-dj\data`（应用内「？帮助」会显示实际路径）。备份 = 复制该目录下的 JSON 文件；升级/重装应用不会删除数据；彻底删除 = 卸载后手动删除该目录。若数据文件损坏，应用会自动把它改名为 `*.corrupt-*` 保留原地并从空状态继续，不会静默清空。凭据（LLM key / 网易云 Cookie / 开放平台凭证）只存本机 `.env` 与 ncm-cli 配置，界面上只显示掩码。

## 数据与隐私

所有用户数据（曲库 / 反馈 / 会话）保存在本地，已被 `.gitignore` 排除，不会进入版本库。对外发送的数据仅限完成功能所必需：LLM 状态解析请求（DeepSeek）、网易云歌单导入与搜索播放请求（官方接口，只传歌单 id / 搜索关键词）、开放平台 API 调用。无遥测。

**两个数据目录（互不互通）：**

| 运行方式 | 数据位置 |
|---|---|
| 开发 / 浏览器模式（`npm start`、`npm run app`） | 项目 `data/` 目录 |
| 安装版（StudyMood DJ Setup 安装的） | `%APPDATA%\studymood-dj\data` |

主进程日志：安装版在 `%APPDATA%\studymood-dj\logs\main.log`。数据迁移/互通在后续版本解决。
