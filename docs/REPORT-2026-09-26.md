## 关键环境知识（踩过的坑）

- electron-builder 打包必须走 npmmirror 镜像（`ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`），否则下载超时；`npm run dist | tail` 管道会掩盖失败 exit code，日志要落盘核对 exe mtime。
- PowerShell 一切输出必须显式 UTF-8（中文 Windows 默认 GBK）；ps1 文件要带 BOM。
- 网易云点 X 会销毁窗口（无信号）；最小化到任务栏/托盘最小化按钮则窗口保留可检测。
- 检查/清数据时的"乱码"多半是管道 GBK 显示假象，用 node utf-8 读文件复核。
- 后台停服务后 8787/8788 可能残留 tsx 子进程，netstat 复查 + taskkill。
- 用户网易云使用习惯：华语主流为主 + 偶尔欧美日本 + 部分纯音乐。
