# 可行性研究：与网易云音乐"完全联动"（2026-09-26）

> **状态更新（同日晚）**：用户已拍板 M8 方向，ncm-cli 联动已全部实现（交付/遥控/全库补位，假 CLI E2E 全通），等开放平台凭证后真机联调。实现细节见 DECISIONS.md 2026-09-26 第二条。

> 结论先说：**可行，且 2026-03 起有了官方路线。** 不需要走逆向 API 的灰色地带就能做到"检测 → 学习 → 生成的歌单直接在网易云里播放"的完整闭环。真正的插件形态（UI 注入客户端）也有路（BetterNCM），但性价比不高，不建议作为主线。

## 背景与目标

用户最终愿景：StudyMood DJ 像"网易云的小插件"一样完全联动——感知正在听的歌、学习偏好、生成歌单后直接在网易云里播放。

## 四层能力现状与可行性

| 层 | 能力 | 现状 | 可行性 |
|---|---|---|---|
| 感知 | 知道网易云在放什么 | ✅ 已上线（SMTC + 进程识别） | 已解决；托盘盲区有兜底方案未做 |
| 理解/学习 | LLM 特征学习、可解释推荐 | ✅ 已上线（本项目核心差异化） | 已解决 |
| 交付 | 生成的歌单**在网易云里播放** | ❌ 目前只给列表，用户手动找歌 | 🎉 **官方新路线：ncm-cli**（见下） |
| 形态 | 界面长在网易云客户端里 | ❌ 桌面小窗（伴随形态） | 可行但不推荐主线（BetterNCM，见下） |

## 关键发现：网易云官方 ncm-cli（2026-03 发布）

网易云音乐开放平台官方 CLI，npm 包 `@music163/ncm-cli`（v0.1.7，2026-08-25 仍在更新，官方 scope）：

- **播放控制**：`play / pause / resume / next / prev / volume / state`，默认输出 JSON
- **搜索**：`ncm-cli search song --keyword "…"` → 拿到 id 后播放
- **歌单管理**：创建/管理歌单、每日推荐、红心歌曲
- **双后端**：优先通过 `orpheus://` URL Scheme 控制**已安装的桌面客户端**（后台常驻进程监听，未运行自动拉起）；也可用内置 mpv 直接播（跨平台）
- **官方授权**：`ncm-cli login` 扫码登录，播放走用户自己的账号版权/VIP 权益——**没有逆向接口的法律与封号风险**
- 官方还配了 AI Agent Skills（github.com/NetEase/skills），定位就是"给 AI Agent 调用"

**前置条件**：需到网易云音乐开放平台（developer.music.163.com）以个人开发者身份入驻，拿 AppId + PrivateKey（`ncm-cli configure`）；需要用户本人注册并提供（涉及账号凭据，按约定须用户操作）。

### 联动闭环长什么样（M8 蓝图）

1. 设置页新增「网易云联动」：检测 ncm-cli 安装/配置状态，引导完成（一次性）
2. 用户在 StudyMood 生成歌单 → 点「▶ 在网易云播放」→ 后端逐首 `search` 匹配曲库歌 → `play` 组队列
3. 桌面客户端开始播放 → 现有 SMTC 感知自动接管 → 正在播放条 + 一键「教它」反馈闭环与现状完全一致
4. 小窗上加 播放/暂停/切歌 按钮（直接调 ncm-cli）→ 真"DJ 遥控器"

### 风险与代价

- ncm-cli 版本尚早（0.1.x），命令面可能变动 → 封装一层 adapter 隔离
- 开放平台个人入驻的审核/限额政策未知 → 用户注册时确认
- `search` 匹配可能有同名不同版（Live/翻唱）→ 按「歌名+歌手+时长」择优，宁可不播也不播错
- 客户端未登录/掉线时 play 失败 → 错误透传到 UI 提示

## 不推荐的路线（记录备查）

1. **逆向 API（NeteaseCloudMusicApi 及其 fork）**：原项目 2024-01 收到网易法律通知后删库，fork 虽能用但无维护、接口随服务端改动逐渐失效；用真实 cookie 调用有账号风控风险。**播放权益也不合法化，收益不如官方路线。**
2. **BetterNCM 注入插件（真·客户端内插件）**：技术上可行（CEF 注入，支持客户端 2.10–3.0），2025-2026 仍活跃但永远在"跟随网易云更新打补丁"，客户端一升级就批量失效；属于灰色地带。**有 ncm-cli 后其价值大降**——桌面小窗置顶伴随形态已能提供"小插件"体验，无需注入。
3. **读客户端本地 cloudmusic.db 兜底托盘盲区**：可行但要跟版本 schema，优先级低；官方 `ncm-cli state` 可作为更稳的兜底信号源。

## 建议路线图

- **M8 交付闭环（下一步主线）**：ncm-cli adapter + 「在网易云播放」+ 小窗播放控制 + 设置页联动引导
- **M9 体验补全**：ncm-cli state 兜底托盘盲区；播放失败降级（mpv 后端 / 仅展示列表）
- **暂不做**：BetterNCM 注入、逆向 API

## 需要用户做的决定

1. 是否采纳 M8 方向（ncm-cli 官方联动路线）
2. 到开放平台注册个人开发者并提供 AppId/PrivateKey（涉及账号凭据，须本人操作；提供后配置方式与现有 LLM key 相同，进设置页）
