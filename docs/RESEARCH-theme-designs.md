## 二、这些主题共用的好设计（可迁移的模式）

1. **角色色板 token 化**：从立绘提取 2-3 个主色（发色/服装）+ 1 个强调色（瞳色/饰品）；大面积低饱和底色 + 小面积高饱和强调（只给按钮/选中态/进度条）。kmeer 主题的常见结构：立绘取色 → 背景渐变 → 控件强调色，三层分明。
2. **三层视觉层级**：背景层（角色立绘/动态元素，低透明度）→ 内容卡片（半透明 + backdrop-blur 毛玻璃）→ 文字（深色高对比）。内容永远压得住背景。
3. **动态元素克制**：动态背景/立绘只在封面、空态、小窗出现；正文列表区保持完全安静——可读性优先是这类主题能日常用的关键。
4. **角色台词情感点缀**：空态/引导页放一句角色台词（kmeer 绘梨衣主题的"这个世界很温柔，但世界不喜欢我"）——小成本高记忆点。
5. **"甜度"控制**：粉白系最易翻车的是全屏糖果色。好评主题都配足白/灰中性层，粉色只出现在强调路径上。
6. **版权规范**：DSH 皮肤标注同人画师、声明禁商用——StudyMood 若用立绘/插画，同款规范（Pixiv 授权或官方素材）。

## 三、对 StudyMood 的映射建议（供新对话实施参考，未实施）

1. **空态与引导页**放绘梨衣元素：立绘/樱花插画（低透明度）+ 台词（如"世界很温柔"），现成的 🎧 空态是最自然的落点；
2. **桌面小窗**做"主题化档位"：小窗面积小、适合放立绘背景（半透明）+ 毛玻璃卡片，参考 Rainmeter 音乐皮肤；
3. **强调色分层**：现有粉（主操作）/紫（次要）基础上，参考爱莉希雅系主题给"选中/播放中"状态一个更亮的强调色，形成反馈语言；
4. **主题强度档位**（素雅 / 主题化）：设置页开关，参考 Comfy 主题可配置思路——尊重"工具优先"的用户；
5. **工程上**：主题 token 已集中在 `styles.css` 顶部 CSS 变量，扩展为多主题只需换一组变量 + 背景图资源，成本低。

- 立绘/插画：优先官方素材（Steam 卡塞尔之门 4K）或取得授权的 Pixiv 同人；B站 UP 的主题包图片不可直接商用复用；
- 角色 IP（龙族·绘梨衣）归江南/灵龙文化及相关游戏方，个人美化学习用途风险低，分发安装包内置立绘需谨慎（DSH 的"仅供学习、禁商用"声明是可借鉴的姿势）。
